<p5ml>

p5ml is a wrapper around p5.js which allows you to write Processing sketches semi-declaratively using HTML, CSS, and less Javascript than usual.

Feel free to play with it in this environment! Make a duplicate of /sketches/template.html and customize using the elements in /src/elements - you can also add custom elements in /custom if you'd like. This environment is also set up with AlpineJS for quick loops and logic.
